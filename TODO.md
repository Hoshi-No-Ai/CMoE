# Roadmap

This initial open-source release focuses on the **simulation training** code for
CMoE (Isaac Gym). The following are planned for future releases:

- [ ] **Deployment code** — sim-to-real deployment for the Unitree G1, including:
  - [ ] MuJoCo playback / evaluation of exported policies
  - [ ] Real-robot deployment (Unitree SDK)
- [ ] Pre-trained policy checkpoints for quick evaluation
- [ ] Additional documentation and tutorials

Contributions and issues are welcome.
